## Brand & Style

The design system establishes an ultra-clean, high-velocity operating environment engineered specifically for FMCG distributors and modern wholesale SMBs. The platform balances institutional financial credibility with the fluid responsiveness of modern web software. It evokes precision, clarity, and unyielding efficiency—eliminating cognitive fatigue during high-volume invoice generation, inventory auditing, and ledger reconciliation.

The aesthetic philosophy merges **Modern Silicon Valley Minimalist SaaS** with **Subtle Glassmorphic Depth**. Interfaces present bright, pristine background canvases, razor-sharp architectural borders, rich obsidian typography, and focused electric hyper-indigo/violet accents. Subtle radiant lighting and multi-layered diffused atmospheric glows soften structural lines, turning dense financial data into an inviting, high-clarity control center.

## Colors

The palette is engineered for high legibility across extensive financial tables and transactional workflows:

- **Primary Canvas & Surfaces**: Surfaces rest on `#FAFBFC`, transitioning to `#FFFFFF` for interactive cards and data grids. Pure white surfaces catch light against faint ambient underlays.
- **Accents**: The primary `#4F46E5` (Hyper-Indigo) commands top-tier calls-to-action, active routes, and key financial states. `#6366F1` and `#818CF8` provide progressive gradient stops and hover highlights, while `#06B6D4` (Electric Cyan) acts as an analytical accent for real-time telemetry, cash flow graphs, and live sync badges.
- **Neutrals & Typography**: Headings and major balance metrics utilize `#0F172A` (Obsidian), secondary meta-details use `#334155`, and inactive or supportive metadata rests in `#64748B`.
- **System States**: Operational feedback relies on `#10B981` (Paid / In Stock), `#F59E0B` (Pending Settlement / Low Stock), and `#E8400D` (Overdue / Critical Discrepancy).
- **Atmospheric Tinting**: Interactive highlights use faint radial overlays of `#6366F1` (at 4% to 8% opacity) layered beneath floating panels to produce soft illumination without degrading contrast.

## Typography

The typographic hierarchy prioritizes scan-speed and zero-error numerical reading:

- **Primary Family (Geist)**: Delivers a clean, contemporary neutral structure across headlines, section anchors, and standard UI copy. Negative letter-spacing in larger tiers reinforces a locked-in, engineered presentation.
- **Data & Numeric Family (JetBrains Mono)**: Applied to all financial figures, invoice IDs, batch numbers, SKU tickers, and tabular ledger tables. Tabular numeral properties (`font-variant-numeric: tabular-nums`) must be enforced globally to guarantee that decimals and currency values maintain fixed vertical alignment during continuous auditing.
- **Scale Usage**: `headline-lg` establishes top-level view identity (e.g., Accounts Receivable, Inventory Summary). `body-md` serves as the primary system interaction size, ensuring maximum information density without sacrificing touch or optical accuracy.

## Layout & Spacing

The layout structure employs a responsive 12-column fluid grid paired with an 8-point base spatial cadence.

- **Breakpoints**:
  - `Desktop (≥1280px)`: Fixed navigation spine (64px collapsed, 260px expanded), 12-column responsive layout, 32px (`margin`) outer offsets, 24px (`gutter`) column separation.
  - `Tablet (768px - 1279px)`: 8-column layout, compact side rail or sticky header, 24px outer margin, 16px gutter.
  - `Mobile (<768px)`: 4-column layout, top navigation bar with bottom sheet drawer overlays, 16px (`margin-mobile`) canvas boundary, 12px (`gutter-mobile`) column gap.
- **Spatial Rhythm**:
  - `space-xs` (4px): Icon-to-text gaps, badge inner vertical padding.
  - `space-sm` (8px): Form input inner paddings, compact row padding, button horizontal spacing.
  - `space-md` (16px): Standard modular card padding, stack spacing in invoice forms.
  - `space-lg` (24px): Inter-card margins, grid grouping separators.
  - `space-xl` (40px): Section divisions between high-level metric summaries and transactional records.

## Elevation & Depth

Hierarchy is established via layered glass surfaces and multi-stop ambient drop shadows rather than heavy border dividers:

- **Level 0 (Canvas Base)**: `#FAFBFC`, static workspace background.
- **Level 1 (Data Cards & Standard Modules)**: `#FFFFFF` with a crisp outline `border: 1px solid #E2E8F0`, underpinned by a soft, diffused ambient shadow:
  `box-shadow: 0 1px 3px 0 rgba(15, 23, 42, 0.03), 0 1px 2px -1px rgba(15, 23, 42, 0.02)`.
- **Level 2 (Hovered Records & Floating Toolbars)**: Subtle lift with atmospheric tinting:
  `box-shadow: 0 10px 25px -5px rgba(79, 70, 229, 0.05), 0 8px 10px -6px rgba(15, 23, 42, 0.03)`. Border shifts dynamically to `#CBD5E1`.
- **Level 3 (Modal Dialogs, Flyouts & Slide-over Sheets)**: Frosted glass backing `rgba(255, 255, 255, 0.85)` with `backdrop-filter: blur(12px)`, edged with a high-definition rim `border: 1px solid rgba(255, 255, 255, 0.8)` and a deep grounding shadow:
  `box-shadow: 0 20px 35px -10px rgba(15, 23, 42, 0.08), 0 1px 3px 0 rgba(15, 23, 42, 0.05)`.
- **Atmospheric Mesh Accents**: Key statistical summary sections utilize localized CSS radial gradients positioned behind the panels:
  `radial-gradient(circle at 50% 0%, rgba(99, 102, 241, 0.08) 0%, rgba(250, 251, 252, 0) 70%)`.

## Shapes

The design system implements a controlled, geometric shape scale calibrated to roundedness token `2` (0.5rem / 8px default):

- **Micro Components (8px / `rounded-md`)**: Checkboxes, status badges, numeric chips, input text fields, and dropdown triggers.
- **Container Elements (16px / `rounded-lg`)**: Metric summary tiles, data table cards, modal dialogs, and slide-in trays.
- **Special Elements (Full Pill / `9999px`)**: Interactive filter chips, user avatar badges, and live connection status indicators.
- **Consistency Rule**: Never mix sharp 0px corners with the primary curve vocabulary; inner nested elements always match their parent's radius minus the container padding to ensure concentric harmony.

  - *Secondary / Outline*: Background `#FFFFFF`, text `#0F172A`, border `1px solid #E2E8F0`. Hover: `#F8FAFC` and border `#CBD5E1`.
  - *Ghost / Table Action*: Padding 6px 10px, text `#64748B`. Hover: text `#0F172A`, background `#F1F5F9`.

- **Form Fields & Inputs**:
  - Surface `#FFFFFF`, border `1px solid #E2E8F0`, border-radius 8px. Height 40px for desktop workflows, 44px on mobile devices.
  - Focus state: Border color `#6366F1`, ring `0 0 0 3px rgba(99, 102, 241, 0.15)`, outline none.
  - Currency/Quantity Fields: Monospace font for prefix/suffix affix elements and values.

- **Data Tables & Ledgers**:
  - Container: White card with 1px border `#E2E8F0` and `rounded-lg`.
  - Header Row: Background `#F8FAFC`, typography uppercase `label-mono-sm`, color `#64748B`, height 40px.
  - Body Rows: Height 48px, subtle bottom border `1px solid #F1F5F9`. Hover state shifts background to `#F8FAFC`. All metrics right-aligned using `JetBrains Mono`.

- **Status Chips & Pills**:
  - Radius `9999px`, padding 2px 10px, typography `label-mono-sm`.
  - Variants:
    - Paid/Dispatched: Background `#ECFDF5`, text `#065F46`, border `1px solid #A7F3D0`.
    - Pending/Review: Background `#FFFBEB`, text `#92400E`, border `1px solid #FDE68A`.
    - Overdue/Alert: Background `#FEF2F2`, text `#991B1B`, border `1px solid #FECACA`.

- **Checkboxes & Radios**:
  - Size 16px × 16px, radius 4px (checkboxes) or full circular (radios).
  - Unchecked: Border `1.5px solid #CBD5E1`, background `#FFFFFF`.

- **Cards & Metric Panels**:
  - Composed of 16px padding, white background, and layered elevation.
  - Metric Header: Geist font, 14px muted description with trailing context icon.
