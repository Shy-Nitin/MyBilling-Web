# MyBilling Homepage (Frontend Only)

## Overview
Modern FMCG and wholesale billing website built exactly according to the Stitch design specifications with interactive frontend demo and integrated physical receipt printer simulation.

## Architecture
- Single Page Application with React 19, TypeScript, and Vite
- Exact Stitch theme styling via Tailwind CSS v4 and Geist / JetBrains Mono typography
- Interactive in-memory billing engine with zero persistence (no backend, no database, no localStorage)
- Integrated Receipt Printer component with realistic thermal stepped printing animation
- Dummy authentication flows for Login and Signup with inline validation and modal feedback
- Interactive Pricing & Plans tier selection
